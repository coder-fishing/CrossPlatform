# Lab 2 — My Card

Digital business-card app built with Expo and TypeScript.

## Run

```bash
pnpm install
pnpm expo install --fix
pnpm start
```

## Structure

- `App.tsx`: screen composition, local `Image`, `ScrollView`, and link actions.
- `components/ContactCard.tsx`: reusable pressable contact card with Ionicons.
- `constants/theme.ts`: shared colors.
- `assets/images/avatar.png`: local avatar asset.

The displayed name, occupation, and contact information are example data; replace them with your own details.
